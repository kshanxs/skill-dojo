# Rhythm and Word Choice

Use this for style modes only. Never use it while proofreading.

Good rhythm serves the sentence's meaning. Do not hit a quota, and do not swap in rarer words to look less predictable. That usually makes prose worse.

## Sentence Length

Read the paragraph aloud. If every sentence takes the same breath, fix the one that matters most:

- Join two short sentences when the second depends on the first.
- Split a long sentence when it holds two separate ideas.
- Put the point you want remembered in a short sentence, or at the end of a long one.

Leave a passage alone if its evenness is doing a job, such as steps in a procedure or a deliberate drumbeat in fiction.

**Before:** Neural network training requires high compute resources. GPUs process matrix multiplications very fast. This speed is necessary for large parameter weights.

**After:** Neural network training needs heavy compute, mostly for matrix multiplication. GPUs do that fast enough to handle large parameter weights.

## Sentence Openings

If three sentences in a row open the same way, recast one. Prefer changing what the sentence leads with over adding a transition word.

## Word Choice

Choose the plainest word that is accurate. Replace a word only when the new one is **more exact**.

| Instead of | Try |
|---|---|
| utilize, leverage | use |
| facilitate | help, allow |
| crucial, pivotal, vital | say what depends on it |
| showcase, highlight, underscore | show |
| robust, seamless | state the actual property |
| landscape, realm | field, market, or the thing itself |
| delve into | examine, study |
| testament to | shows, is evidence of |

Keep the author's own habitual words, even plain or unfashionable ones. They are part of the voice.

## Punctuation

Vary punctuation only where it changes the sense. A comma, a colon, parentheses, or a new sentence can usually replace an em dash. If the author uses em dashes on purpose, or the project's style guide allows them, leave them.
